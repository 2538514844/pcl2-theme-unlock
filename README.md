# PCL2 主题解锁版

基于 **PCL2 2.13.1.1（正式版 408）** 的本地修改版：解锁全部启动器主题，关闭自动更新与公告拉取。

## 改了什么

- 解锁全部主题（含隐藏主题），去掉灰色遮罩层与赞助/等级校验
- 主题配色与标题栏渐变按 **PCL 2.14.0.0** 的官方色表还原
- 移除自动更新、自动获取公告与联网配置（保留本地缓存读取）
- 「检查更新」按钮改为提示文字

## 使用方法

1. 备份你自己目录里的 `Plain Craft Launcher 2.exe`
2. 把本仓库的 exe 放进 PCL 目录，覆盖同名文件
3. 正常启动即可
